# 万界冒险团 V0.35：主界面试玩版

第一次试玩请先看 `README_V035.md`；美术替换路径见 `ART_SPEC_V035.md`，人工验收见 `PLAYTEST_V035.md`。本项目在 V0.31 基础上增量开发，保留原有玩法与存档。下文保留早期版本的技术说明，以 V0.35 专文为当前界面操作说明。

这是在 V0.2A 自动战斗、装备和存档基础上增量开发的 Godot 4.3 Windows 单机项目。V0.3 的双世界、十角色、Boss、招募、分解重铸、策略和统计说明见 `README_V03.md`。

## 当前可玩内容

- 1060×520 的俯视角战斗地图，包含可绕行的岩石障碍与 AStarGrid2D 网格寻路。
- 四人小队：赵云、刘备、皮卡丘、卡比兽。
- 自动索敌、移动、普通攻击、伤害、防御、死亡、敌人波次及随波次成长。
- 四个代表性主动技能：突进伤害、单体治疗、连锁雷击、自我恢复。
- 三国与宝可梦两类敌人占位单位。
- 左键设置四人集结点；空格暂停/继续；全灭后 R 重开。
- 基础 HUD、队伍生命/技能状态、击杀/波次/计时和战斗日志。
- JSON 驱动的角色与技能数值，便于后续扩展。
- 无外部图片依赖的 Q 版矢量占位美术，后续可替换为分层换装资源。
- 四名角色各有主手、副手、头盔、衣服、手套、鞋子、项链、双戒指，共 36 个独立栏位。
- 怪物死亡后按地图等级与品质权重随机生成装备，并自动拾取进 120 格背包。
- 白、绿、蓝、紫、橙五档品质；基础属性、词条数量与词条数值均受品质预算影响。
- 生命、攻击、防御、暴击率、暴击伤害、攻击速度、冷却缩减、物理增伤、元素增伤、生命恢复共 10 种词条。
- 背包支持部位/品质筛选、完整详情、角色切换、穿戴、替换、卸下和属性差值预览。
- 装备属性真实参与战斗；装备变化按基础值重新计算，不会永久叠加，并保持当前生命比例。
- 本地 JSON 存档保存版本号、完整装备实例与四名角色的装备关系。

按 `B` 或点击底部“背包”打开界面。背包打开时战斗自动暂停。

## 运行（Windows）

1. 安装 Godot 4.3 或更新的 Godot 4.x 标准版（不需要 .NET 版）。
2. 启动 Godot，在项目管理器中点击“导入”。
3. 选择本目录中的 `project.godot`。
4. 打开项目后按 `F6`/`F5`，或点击右上角运行按钮。

命令行已有 Godot 时，也可以在本目录执行：

```powershell
godot --path . --editor
```

直接启动游戏：

```powershell
godot --path .
```

## 导出 Windows 64 位

1. 在 Godot 中打开“编辑器 → 管理导出模板”并安装与编辑器版本一致的模板。
2. 打开“项目 → 导出”，添加预设“Windows Desktop”。
3. 架构保持 `x86_64`，导出路径可设为 `builds/万界冒险团.exe`。
4. 点击“导出项目”。如需单文件便携版，勾选“嵌入 PCK”。

## 数据扩展入口

- `data/actors.json`：角色基础属性、定位、颜色及技能引用。
- `data/skills.json`：技能类型、倍率、范围与冷却。
- `data/equipment.json`：9 个栏位、5 档品质、装备模板、10 种词条及数值上限。
- `data/loot_tables.json`：地图等级、普通/测试掉率和品质权重。
- `scripts/unit.gd`：通用单位状态机、伤害/治疗和技能行为。
- `scripts/battle_controller.gd`：寻路、生成、波次和战斗调度。
- `scripts/equipment_generator.gd`：随机实例生成器，模板与实例分离。
- `scripts/inventory_manager.gd`：背包、穿戴关系、属性聚合和版本化存档。
- `scripts/inventory_ui.gd`：筛选、详情、比较和装备操作界面。

新增角色时，优先在 JSON 中添加配置；只有出现新的技能行为类型时才修改脚本。正式美术接入时可将 `BattleUnit._draw()` 替换为分层 Sprite2D 节点，战斗数据无需改动。

## 数值结算规则

- 生命、攻击、防御和生命恢复为同类加算；攻击与防御直接进入既有伤害公式。
- 物理/元素增伤分别加算后作为对应攻击的独立乘区。
- 暴击基础倍率 150%，装备暴伤加算；基础暴击率 5%，总暴击率上限 75%。
- 攻速缩短普通攻击间隔，上限 150%，最终攻击间隔不低于 0.25 秒。
- 冷却缩减上限 50%，技能实际冷却为基础冷却乘以 `1 - 冷却缩减`。
- 每次换装都从角色基础值与当前 9 个栏位重新汇总；最大生命改变时保持原生命百分比。

## 验证说明

工程附带 `verify_project.ps1`。它会检查项目文件、角色技能引用、9 个装备栏和 10 种词条；找到 Godot 后还会运行原战斗回归与 V0.2A 装备/掉落/存档自动验收。

```powershell
powershell -ExecutionPolicy Bypass -File .\verify_project.ps1
```

便携版 Godot 不在 PATH 时：

```powershell
$env:GODOT_BIN = 'D:\Tools\Godot_v4.3-stable_win64_console.exe'
powershell -ExecutionPolicy Bypass -File .\verify_project.ps1
```

测试模式可直接用 `--loot-test` 启动，掉落率为 100%，并大幅提高高品质权重。该模式仍使用正常存档；自动化使用的 `--equipment-test` 会改用独立测试存档。
