# 万界冒险团 V0.3 双世界冒险版

V0.3 在通过人工测试的 V0.2A 工程上增量开发，保留 AStarGrid2D 寻路、四人自动战斗、装备背包和本地存档。

## 运行

使用 Godot 4.3 或更新的 Godot 4.x 标准版导入 `project.godot`，按 F6/F5 运行。Godot 4.7 已避免 `draw_ellipse` 名称冲突。

操作：左键地图设置集结点，空格暂停，B 打开装备背包。顶部新增“世界地图、招募编队、分解重铸、战斗策略、战斗统计”五个入口。

## V0.3 内容

- 虎牢关与常青森林两张独立挂机地图，分别掉落虎符和精灵结晶。
- 张飞、典韦、赵云、诸葛亮、刘备、吕布、皮卡丘、卡比兽、耿鬼、超梦共十名角色；每人保留独立九栏装备。
- 招募令随机招募、世界材料定向兑换、四人队伍自由替换；吕布和超梦由传奇 Boss 首胜永久解锁。
- 吕布 Boss 具有范围横扫与半血狂暴；超梦 Boss 具有精神风暴与周期护盾。重复挑战发放世界材料。
- 雷霆追击、荆棘反击、疫毒蔓延、破盾震爆四种配置化特殊词条，所有派生伤害禁止递归触发。
- 中毒、护盾、Boss 硬控递减/累计上限与独立嘲讽机制。
- 非穿戴装备分解、紫橙确认、材料收益、单词条候选重铸、保留旧词条或接受新词条。
- “稳健/猛攻”两套可保存策略，控制治疗生命阈值、自疗阈值与范围技能敌人数阈值。
- 基于真实伤害/治疗/技能/击杀/掉落事件的实时统计和资源每分钟估算。

## 存档与迁移

- 装备实例仍由 `wanjie_v02_save.json` 保存，V0.2A 装备和随机词条原样保留。
- V0.3 进度使用 `wanjie_v03_progress.json`，保存材料、招募令、角色池、四人队伍、Boss 首胜与两套策略。
- 缺少 V0.3 字段的旧数据会使用默认值补齐，不重置旧装备。
