# 万界冒险团 V0.6

V0.6 从远端 V0.5 提交 `da6b18e` 派生，稳定 `main` 未被改写。工程保持 `project.godot` 的 Godot 4.7 feature 标记与原应用名，从而继续使用原用户目录并执行只读迁移。

## 游戏循环

玩家从三国全局第1关开始挂机战斗。每关清理3波，后续关卡只在前一关首次通关后开放；三国第10关的吕布是世界门槛，击败后永久开放宝可梦全局第11—20关。超梦接入第20关。世界Boss仍可在对应世界主线完成后重复挑战。

击杀经验由关卡怪物等级与普通/精英/Boss类型共同决定，四名上阵角色共享。角色等级上限仍为60，不等同于关卡难度Lv.1—20。高等级角色反复刷低级关时经验递减，离线收益不发经验。

顶栏“角色”、底栏“角色/技能/背包”和快捷键 B 均可进入统一角色页：

- 左栏查看全部已获得角色，按等级、战力、定位排序；查看不会改编队。
- 中栏显示角色、经验和9个原装备栏；一键优化最多3件，仅紫色以上且不拿其他角色装备。
- 右栏提供人物属性、角色技能、背包、成长与定位四个标签。
- 装备锁定写在原物品实例中，并阻止出售、分解与重铸。
- 专属主动/被动沿用 V0.5；通用主动/被动可学习、装备、升级与调整释放优先级，并进入同一自动战斗状态机。

## 运行

推荐 Windows Godot 4.7 标准版。导入 `project.godot` 后按 F5。无需 .NET、插件或第三方依赖。完整命令行验证：

```powershell
$env:GODOT_BIN = 'D:\Tools\Godot_v4.7-stable_win64_console.exe'
powershell -ExecutionPolicy Bypass -File .\verify_project.ps1
```
