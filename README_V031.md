# 万界冒险团 V0.31 · 可视化试玩与新手引导

这是 V0.3 项目的增量版本，保留四人自动战斗、AStarGrid2D 寻路、双世界、装备、招募、Boss、分解重铸、策略、统计和原有存档。Godot 4.3 标准版可直接打开 `project.godot`；Windows 上按 F5 开始游戏。

## 第一次怎么玩

1. 左侧引导先提示你点“招募”，用初始招募令获得伙伴。引导不挡住地图，自动战斗照常进行。
2. 怪物被击败后自动拾取装备、世界材料和金币。蓝、紫、橙装备会在战场顶部弹出品质颜色提示。
3. 点“背包 / 装备”，选物品，查看右侧绿色/红色属性差值，再选角色穿戴。可选择任意已招募角色，包括宝可梦。
4. 在“招募”里用材料定向兑换更多伙伴；在“伙伴 / 编队”更换四人上阵阵容。
5. “世界地图”切换虎牢关和常青森林；“Boss挑战”先查看属性及推荐等级，再确认开战。
6. “技能策略”设置自动释放阈值，“战斗统计”查看真实伤害、DPS 和资源收益。

右上角“设置 / 引导”可以重新查看引导，不会清空进度。回顾模式可逐步点“已了解，下一步”；第一次游戏的引导按真实招募、击杀、掉落、穿戴和编队状态推进。左键地图设置集结点；空格暂停；B 打开背包；全灭时 R 重开。

## 本阶段变化

- 战斗地图常驻中央；顶部显示世界、地图、金币、状态、统计和清晰文字入口；左侧是引导，右侧是当前目标；底部是四人信息与战斗日志。
- 功能面板改为右侧抽屉，打开时暂停战斗，关闭后继续；背包为专用整理界面。两个界面会互斥，避免互相覆盖。
- 角色卡显示名字、定位、生命、护盾、中毒、攻击、防御和技能。没有正式头像时使用文字首字占位。
- 暴击、治疗、护盾、中毒和稀有掉落采用区别明显的颜色反馈。装备品质颜色沿用 `data/equipment.json` 中的统一配置。
- 金币按地图等级在怪物死亡时获得，并保存到 V0.31 进度文件；旧 V0.3 文件缺少金币字段时按 0 读取。
- 美术资源可在 `data/art_resources.json` 关联 PNG。缺图会回退到旧占位画面，不会使游戏无法运行。详见 `ART_SPEC_V031.md`。

## 存档与兼容

Godot 将进度、招募、策略和引导状态保存在 `user://wanjie_v03_progress.json`，背包和装备仍在 `user://wanjie_v02_save.json`。新字段只做兼容性追加；旧 V0.3 存档的队伍、角色、材料和装备不会重置。检测到旧背包但没有进度文件时，不强制弹出新手引导，可在设置中主动重看。

## 验证与交付边界

`verify_project.ps1` 运行旧版战斗/装备/存档测试以及 V0.31 引导和界面集成测试。具体结果见 `TEST_REPORT_V031.md`，手动试玩步骤见 `PLAYTEST_V031.md`。本版没有新增地图、正式立绘、完整换装系统或技能树；资源文件夹和加载接口不代表已完成正式美术。
