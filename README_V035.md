# 万界冒险团 V0.35：主界面试玩版

本版在 V0.31 工程上增量改造主界面。中央仍是原有四人自动战斗地图；底部是四名伙伴状态卡和主要功能；右下是收益、目标、日志、统计四个独立入口。战斗、装备、招募、Boss、寻路和存档仍使用原系统。

## 最快试玩

1. 使用 Godot 4.3 标准版，在项目管理器中点“导入”，选本文件夹里的 `project.godot`。
2. 双击项目，按 `F5` 或点右上角“运行项目”。首次导入 PNG 请等待编辑器扫描完成。
3. 新存档先按引导点底部“招募”。随后战斗自动进行，怪物掉落自动拾取。
4. 点底部“背包”查看、穿戴装备；点“伙伴”调整队伍；点“世界”切换地图；点“Boss”查看挑战。
5. 右下“收益、目标、日志、统计”查看详情，关闭面板继续战斗。`B` 打开背包，空格暂停，左键点击地图设置集结点。

没有 Windows EXE 也可以直接在 Godot 中试玩。工程无需联网或额外插件。项目名在 `project.godot` 中仍为 V0.31，这是为保留原来的 Godot 本地存档目录；游戏窗口与界面显示 V0.35。

## 本版界面变化

- 1440×768 基准布局；1920×1080 通过统一缩放与居中留白适配。
- 战斗地图占据中央，不再由大面积固定文字面板遮挡。
- 四名出战角色底部状态卡显示头像或文字占位、生命数值、血条与重要状态。
- 原先顶部堆叠入口改为底部两行文字按钮；收益、目标、日志、统计另设一列入口。
- 引导进行中只出现引导提示；引导结束后才显示当前目标提示，避免重复。
- 虎牢关接入明亮的占位地图美术与岩石障碍，赵云和刘备接入试制透明角色图；其他角色或地图在资源缺失时继续使用代码占位画面。
- 美术路径与可选裁切区域集中于 `data/art_resources.json`；不是正式分层换装美术。

## 验证

在项目目录运行 `verify_project.ps1`。设置 `GODOT_BIN` 为 Godot 4.3 控制台程序路径后，脚本会运行 V0.1、V0.2A、V0.3、V0.31 回归和 V0.35 界面检查。具体结果见 `TEST_REPORT_V035.md`。

## 本版边界

V0.35 没有增加新的角色、装备词条或地图数量；没有制作正式时装或全部头像。宝可梦角色仍用可替换的占位形象。Godot 项目本身可运行，但本次没有 Windows 导出模板，因此没有声称已导出 EXE。
