# V0.9 技能效果与第三关稳定性修复报告

## 稳定性根因与修复

第三关高顺的 `burning_aura` 把 Boss 节点直接保存在玩家的 `burn_source`。Boss 死亡并 `queue_free()` 后，燃烧下一跳仍把该悬空对象传入 `take_damage()`；`source is BattleUnit`、伤害类型解析及死亡日志随后访问已释放实例，导致调试器中断。

燃烧、中毒、持续治疗现在保存施加时的来源快照（角色 ID、名称、阵营、伤害类型、物理/元素/最终增伤和必要特效）。每次延迟结算仅使用仍有效的实时节点，否则使用快照；失效来源不再触发反击或击杀被动，但伤害/治疗/击杀统计仍保留来源 ID。伤害分担来源失效时会安全取消，净化会同时清理状态来源。

第三关实测覆盖高顺施加燃烧后死亡、继续运行 10 秒、最后一跳击杀英雄、切关链路、重复通关三次、首通解锁第 4 关及自动推关开关。主线仍严格停在第 3/3 波。

## 技能修复摘要

- 三国/宝可梦：赵云安全突进；张飞嘲讽、护盾与限时减伤；典韦残血强化；黄忠及路卡利欧必中；超梦改为目标区域爆发；小火龙燃烧延长限制为最多 10 秒；貂蝉描述与魅惑控制一致。
- 龙族：路明非每场每目标一次救援并带独立 45 秒间隔；零仅复制存活队友白名单直接伤害且不递归；矢吹樱移动后下一击强化；诺诺锁定高威胁目标；凯撒对破甲目标获益；绘梨衣连续施法后短时承伤风险；源稚生仅在近敌存在时减伤；源稚女异常/控制强化受上限约束。
- 逆水寒：血河多目标穿透；碎梦末段低血斩杀；神相燃烧联动；素问持续治疗与单次有限净化；九灵改用独立 `medicine_avatar` 药人模板，继承召唤者归属并附加魂蛊毒伤，不带 Boss 身份。
- 魔兽世界：盾墙补齐减伤；复苏之风改为低血持续恢复；嗜血同时推进冷却并提供团队攻速；风怒严格在第 3/6/9 次普攻造成元素追击；杀戮机器联动冰霜/减速；恶魔变形具有 7 秒持续与 18 秒内置冷却；暴风雪使用独立冰霜 DOT/减速而非燃烧；寒冰指覆盖主动技能伤害。
- 金庸：乔峰擒龙功补齐直接物理伤害；段誉保留远程安全距离与闪避；任盈盈琴刃改为元素范围伤害、减速及短扰乱，不再燃烧。
- 通用主动：清理穿云箭、背水一击、种子炸弹等无效 UI 字段；自身防御明确作用施法者；危急护盾按生命比例选人；江湖护体优先前排；范围、直线穿透、冰音范围、龙焰范围、污泥毒伤三层上限、炼金封印削盾、龙血沸腾攻击强化和战斗怒吼团队增益均接入实战。
- 通用被动：友军守护改为 220 范围动态光环并设 40%总上限；冰霜精通强化减速和持续时间；多段增益覆盖专属/通用多段；治疗、燃烧及异常增益覆盖对应路径；黄金瞳提供真实命中修正；炼金亲和同时强化护盾和破甲；回响不递归；同目标连击切换目标即重置；击杀收益补齐攻击强化与紫霞冷却推进；玉女心经增加有限第四击收益。

主动技能默认仍不全局暴击，避免无依据的数值膨胀；仅明确联动通过条件增伤或必中实现。
